## Context

People use Aikonic's AI products to search their transcripts and documents, in more than one language:

- **My part:** I built the multilingual enterprise search, and shipped 21 agent tools alongside it
- **Who uses it:** 10,000+ people

## Search that shows where it found the answer

A result from a transcript only helps if you can go straight to the moment it came from:

- **Two kinds of retrieval:** semantic and keyword search combined, with tuned chunking
- **Exact citations:** each result cites the exact timestamp in the source
- **Chunked with that in mind:** transcripts are split so every passage maps back to its timestamp

## 21 tools for the agent

Tools for retrieval, editing, summarization and memory:

- **Scoped to the person:** each tool stays inside the user's folder permissions
- **Tested:** regression tests for both the tools and the search
- **One orchestration layer:** search and the agent tools share it, with workspace isolation between organizations
